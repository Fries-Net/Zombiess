# Original model provenance

Imported from `FriesnetGuns(notall).zip`: 66 Blockbench 4.10 Java block models, 2,123 cubes and
111 embedded texture records. Archive SHA-256:
`bf98b18a649ca65e949e39babc9abe5ce58a5c2db90c02082cc87beee8555627`.

The original archive is read-only input and remains outside the repository. These canonical source
documents retain geometry, origins, rotations, face texture indices/UVs, embedded PNG bytes and
authored display values. Local texture filesystem paths are removed. `provenance.json` records each
original document hash and the canonical bundle hash; `ids.json` locks variant identities, including
filenames that normalize to the same spelling. Re-import with `python tools/resource_pack.py import`
and the original ZIP to reproduce this bundle. No replacement model or texture is synthesized.
